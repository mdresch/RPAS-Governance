# RPAS Sovereign Governance Authority (Courthouse)

**Baseline:** CSR-42 (Certified)
**Status:** Operational / Sealed

## 🏛️ Purpose
This repository contains the source code for the **RPAS Sovereign Governance Courthouse**, the authoritative substrate for the RPAS-CM ecosystem. It is designed to physically and mechanically enforce the process integrity of autonomous rituals through **Law-as-Code** and **Topology Sovereignty**.

## 📜 Jurisdictional Reference
This system is governed by the **[CSR-42 Audit Brief](certification/CSR-42/audit_brief.md)**. The brief serves as the "True Constitution" of the infrastructure, defining the non-violable G1–G6 invariants.

## 🏗️ Repository Structure
This project follows a triple-repo strategy to prevent authority leakage:
- **RPAS-Governance** (This Repo): The authoritative courthouse, core laws, and persistence layers.
- **[RPAS-Governance.Client](RPAS.Governance.Client/)**: The Petitioner SDK and Onboarding Kit for consumer integration.
- **[RPAS-Governance-Certs](certification/CSR-42/)**: Read-only certification and audit artifacts.
